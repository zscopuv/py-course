**Lesson 33: Asynchronous Programming with asyncio**

---

### Welcome Back! 🚀

**Asynchronous programming** lets a program make progress on other work while it waits for slow operations such as network responses.

---

### 1. An Async Function

```python
import asyncio

async def make_tea() -> str:
    await asyncio.sleep(1)
    return "Tea is ready"

print(asyncio.run(make_tea()))
```

`await` pauses this task without blocking the entire program.

---

### 2. Running Independent Tasks Together

```python
import asyncio

async def fetch_name(number: int) -> str:
    await asyncio.sleep(0.1)
    return f"result-{number}"

async def main() -> None:
    results = await asyncio.gather(fetch_name(1), fetch_name(2), fetch_name(3))
    print(results)

asyncio.run(main())
```

---

### 3. When to Use asyncio

Use it mostly for I/O-bound work: HTTP requests, database calls, files, or waiting for timers. It does not automatically make CPU-heavy calculations faster.

---

### 📝 Notes

- Call `asyncio.run()` once at the top level of a small script.
- Every function you `await` must be declared with `async def`.
- Use timeouts and error handling around real network operations.
