### Welcome Back! 🚀

Security is a set of engineering habits: minimize trust, validate input, keep secrets out of code, and use established cryptographic primitives rather than inventing them.

---

### 1. Compare Secrets in Constant Time

```python
import hmac
import os

expected = os.environ.get("WEBHOOK_SECRET", "development-only-secret")

def valid_signature(received: str) -> bool:
    return hmac.compare_digest(received, expected)

print(valid_signature("not-the-secret"))
```

`compare_digest` avoids the timing behavior of ordinary equality checks for secret values. In production, require the secret from a managed environment rather than using a fallback.

---

### 2. Parse Data, Never Execute It

```python
import json

payload = '{"enabled": true, "retries": 3}'
config = json.loads(payload)
if not isinstance(config.get("retries"), int):
    raise ValueError("retries must be an integer")
print(config["retries"])
```

Never use `eval` or `exec` to parse user-controlled configuration. They grant code execution, not merely data decoding.

### 📝 Notes

- Parameterize SQL queries; do not compose SQL by formatting untrusted strings.
- Pin and update dependencies, and review advisories for deployed applications.
- Apply least privilege to tokens, files, database accounts, and service identities.
- Do not log access tokens, passwords, session cookies, or full personal records.
