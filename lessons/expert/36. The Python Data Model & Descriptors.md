### Welcome to the Expert Course! 🧠

Python operators, attribute access, and built-ins work through a **data model**: well-known methods such as `__len__`, `__iter__`, and `__get__`. Implement them only when they make an object feel natural to use.

---

### 1. Make a Domain Object Behave Like a Container

```python
class Inventory:
    def __init__(self, items: dict[str, int]) -> None:
        self._items = dict(items)

    def __len__(self) -> int:
        return sum(self._items.values())

    def __contains__(self, name: object) -> bool:
        return name in self._items

    def __iter__(self):
        return iter(self._items.items())

stock = Inventory({"cable": 3, "adapter": 1})
print(len(stock), "cable" in stock, list(stock))
```

`len(stock)`, `in`, and `for` now use the object’s protocol methods rather than special cases in your application code.

### 2. Validate Attributes with a Descriptor

Descriptors define `__get__`, `__set__`, or `__delete__`. They are the mechanism behind properties, methods, and many ORM fields.

```python
class PositiveInt:
    def __set_name__(self, owner, name) -> None:
        self.storage_name = f"_{name}"

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value: int) -> None:
        if not isinstance(value, int) or value < 0:
            raise ValueError("expected a non-negative integer")
        setattr(instance, self.storage_name, value)

class RetryPolicy:
    attempts = PositiveInt()

    def __init__(self, attempts: int) -> None:
        self.attempts = attempts

print(RetryPolicy(3).attempts)
```

---

### 3. Attribute Lookup Matters

For `obj.name`, Python first checks data descriptors on the class, then `obj.__dict__`, then non-data descriptors and class attributes. `__getattr__` is called only after normal lookup fails; use it for deliberate fallbacks, not to hide mistakes.

### 📝 Notes

- `__repr__` should be unambiguous and useful while debugging; `__str__` is for people.
- Return `NotImplemented` from binary operator methods when another type may handle the operation.
- Prefer a `@property` for one-off validation. Use a descriptor when the rule is reusable across fields.
