### Welcome Back! 🚀

Web scraping means collecting information from web pages. In this lesson, you will use `requests` to download a page and **BeautifulSoup** to read its HTML.

---

### 1. Installing the Tools

```bash

```

---

### 2. Reading a Page

```python
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
response = requests.get(url, timeout=10)
response.raise_for_status()

soup = BeautifulSoup(response.text, "html.parser")
print(soup.title.get_text(strip=True))
```

`raise_for_status()` turns unsuccessful HTTP responses into errors instead of silently using a bad response.

---

### 3. Selecting Elements

```python
from bs4 import BeautifulSoup

html = """
<ul>
  <li class="book">Python Basics</li>
  <li class="book">Clean Code</li>
</ul>
"""

soup = BeautifulSoup(html, "html.parser")
books = soup.select("li.book")

for book in books:
    print(book.get_text(strip=True))
```

---

### 4. Be a Respectful Scraper

- Read a website's terms and `robots.txt` before scraping it.
- Request pages slowly; never overload a server.
- Do not scrape private, copyrighted, or personal data without permission.
- Prefer an official API when one is available.

---

### 📝 Notes

- HTML can change, so selectors should be as specific and stable as possible.
- Use a timeout for every network request.
- Save only the data you need, and validate it before using it.
