### 2. Your First Window

```python
import customtkinter as ctk

app = ctk.CTk()
app.title("Greeting App")
app.geometry("360x180")

label = ctk.CTkLabel(app, text="Hello, desktop Python!")
label.pack(pady=40)

app.mainloop()
```

`mainloop()` keeps the window open and listens for user actions.

---

### 3. Responding to a Button Click

```python
import customtkinter as ctk

app = ctk.CTk()
app.title("Greeting App")

name_entry = ctk.CTkEntry(app, placeholder_text="Enter your name")
name_entry.pack(padx=30, pady=(30, 10))

message = ctk.CTkLabel(app, text="")
message.pack(pady=10)

def greet():
    name = name_entry.get().strip() or "friend"
    message.configure(text=f"Hello, {name}!")

ctk.CTkButton(app, text="Greet me", command=greet).pack(pady=10)
app.mainloop()
```

---

### 📝 Notes

- Use `pack()`, `grid()`, or `place()` to position widgets; do not mix `pack()` and `grid()` in the same parent widget.
- An entry's `.get()` method reads its text, and `.configure()` updates widget options.
- Keep event-handler functions small and give them clear names.
