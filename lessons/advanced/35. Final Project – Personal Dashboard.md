# Python for Beginners  
**Lesson 35: Final Project – Personal Dashboard**

---

### Welcome Back! 🚀

For your final project, combine the skills from this course into a **Personal Dashboard**. It can track tasks, expenses, study time, or any information that matters to you.

---

### 1. Plan Before You Build

Write a short plan that answers these questions:

- Who will use the dashboard?
- What problem will it solve?
- What data will it store?
- Which features are essential for the first version?

Start small. A working dashboard with three useful features is better than an unfinished app with twenty ideas.

---

### 2. Suggested Features

```python
features = [
    "Add, edit, and remove records",
    "Store data in SQLite or JSON",
    "Show totals or summaries",
    "Filter records by category or date",
    "Test important calculations",
]

for feature in features:
    print(feature)
```

You may build the dashboard as a Flask website, a CustomTkinter desktop app, or a command-line application.

---

### 3. A Practical Project Structure

```text
personal_dashboard/
├── README.md
├── requirements.txt
├── app.py
├── database.py
├── services.py
└── tests/
    └── test_services.py
```

Keep data access, business logic, and user-interface code in separate files when the project grows.

---

### 4. Definition of Done

Before calling the project finished, make sure you can:

1. Install and run it using instructions in the README.
2. Add valid data and see it appear correctly.
3. Handle at least one invalid input gracefully.
4. Run automated tests for your core calculations.
5. Explain one improvement you would make next.
