### Welcome Back! 🚀

Decorators transform callable behavior. Context managers make setup and cleanup reliable, even when an exception interrupts the work.

---

### 1. Measure a Function Without Changing Its Body

```python
from functools import wraps
from time import perf_counter

def timed(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        started = perf_counter()
        result = function(*args, **kwargs)
        print(f"{function.__name__}: {perf_counter() - started:.6f}s")
        return result
    return wrapper

@timed
def total_to(limit: int) -> int:
    return sum(range(limit))

print(total_to(10_000))
```

`@wraps` preserves the wrapped function’s name, documentation, and `__wrapped__` link—important for tools and debugging.

### 2. Create a Transactional Context Manager

```python
from contextlib import contextmanager

@contextmanager
def transaction(events: list[str]):
    events.append("BEGIN")
    try:
        yield events
    except Exception:
        events.append("ROLLBACK")
        raise
    else:
        events.append("COMMIT")

log: list[str] = []
with transaction(log):
    log.append("write")
print(log)
```

The code before `yield` is entry; the `except`/`else` code is guaranteed exit handling. Re-raising preserves failure instead of silently pretending work succeeded.

### 📝 Notes

- A decorator may be a function or a callable object; keep its contract documented.
- Use `with` for files, locks, database sessions, temporary resources, and tracing scopes.
- A context manager should suppress an exception only when that is an explicit, safe policy.
