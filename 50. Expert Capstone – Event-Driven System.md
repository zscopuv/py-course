### Welcome to the Final Expert Challenge! 🏁

Build a small, production-minded **event-driven system**: for example, a job tracker, notification pipeline, telemetry collector, or collaborative task board. The important part is its design, not its theme.

---

### 1. Define a Stable Event Contract

```python
from dataclasses import dataclass
from datetime import datetime, timezone

@dataclass(frozen=True)
class JobCompleted:
    job_id: str
    duration_ms: int
    occurred_at: datetime

    @classmethod
    def create(cls, job_id: str, duration_ms: int) -> "JobCompleted":
        if duration_ms < 0:
            raise ValueError("duration cannot be negative")
        return cls(job_id, duration_ms, datetime.now(timezone.utc))

print(JobCompleted.create("job-12", 84))
```

Events are facts, so immutable data is a good fit. Include identifiers, an explicit schema version if events leave the process, and timestamps in UTC.

---

### 2. Separate the Pipeline

```text
producer → validated event → queue/store → handler → observable side effect
                              ↓
                       retry / dead-letter policy
```

Implement one path end to end before adding infrastructure. A command creates an event; a handler updates a read model or sends a notification; tests prove duplicates and failures are handled deliberately.

---

### 3. Expert Definition of Done

1. A documented architecture and setup guide.
2. Validated event types and deterministic domain rules.
3. A bounded concurrent worker or clearly synchronous alternative.
4. Idempotent handling or a documented deduplication strategy.
5. Timeouts, retries, structured logs, and safe error reporting.
6. Unit tests plus at least one integration test.
7. Automated formatting, type checks, and test commands.

### 📝 Notes

- Start with an in-memory queue, then swap in durable infrastructure only when requirements demand it.
- Instrument queue depth, handler latency, failures, and retry counts.
- Make graceful shutdown part of the design: stop intake, finish or cancel work, then close resources.
