### 2. A Line Chart

```python
import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr"]
sales = [12, 18, 15, 24]

plt.plot(months, sales, marker="o")
plt.title("Monthly Sales")
plt.xlabel("Month")
plt.ylabel("Sales")
plt.grid()
plt.show()
```

---

### 3. A Bar Chart

```python
import matplotlib.pyplot as plt

categories = ["Food", "Travel", "Books"]
amounts = [90, 45, 30]

plt.bar(categories, amounts, color="steelblue")
plt.title("Expenses by Category")
plt.ylabel("Amount")
plt.tight_layout()
plt.show()
```

---

### 4. Choosing an Honest Chart

- Use bar charts to compare categories and line charts to show change over time.
- Label axes and include units when relevant.
- Do not crop axes in a way that exaggerates small differences.
- Use colors with enough contrast for readers to distinguish them.

---

### 📝 Notes

- `plt.show()` displays a chart in a local Python session.
- `plt.savefig("chart.png")` saves the current chart to a file.
- Create one chart per question so the message stays clear.
