### Welcome Back! 🚀

Expert async code makes task lifetimes visible. A parent should own, await, cancel, and observe the child tasks it starts.

---

### 1. Bound Concurrent Work

```python
import asyncio

async def fetch(identifier: int, limit: asyncio.Semaphore) -> str:
    async with limit:
        await asyncio.sleep(0.01)
        return f"item-{identifier}"

async def main() -> None:
    limit = asyncio.Semaphore(3)
    results = await asyncio.gather(*(fetch(i, limit) for i in range(8)))
    print(results)

asyncio.run(main())
```

The semaphore prevents an unbounded fan-out from overwhelming a remote service or local resources.

---

### 2. Put a Deadline Around an Operation

```python
import asyncio

async def slow_operation() -> str:
    await asyncio.sleep(1)
    return "done"

async def main() -> None:
    try:
        result = await asyncio.wait_for(slow_operation(), timeout=0.05)
    except asyncio.TimeoutError:
        result = "timed out"
    print(result)

asyncio.run(main())
```

Timeout cancellation is cooperative: code must reach an `await` or otherwise respond to cancellation. Clean up resources in `finally` blocks.

### 📝 Notes

- In Python 3.11+, `asyncio.TaskGroup` is the preferred structured way to run related tasks.
- Do not create background tasks and forget them; retain a reference and define error reporting and shutdown.
- `asyncio.gather` has configurable exception behavior—choose it deliberately rather than losing failures.
