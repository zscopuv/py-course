### 2. Creating a DataFrame

```python
import pandas as pd

expenses = pd.DataFrame(
    {
        "category": ["Food", "Travel", "Food", "Books"],
        "amount": [12.50, 40.00, 18.25, 25.00],
    }
)

print(expenses)
print(expenses["amount"].sum())
```

A `DataFrame` is a table. Each column has a name, and each row represents one record.

---

### 3. Filtering and Grouping

```python
import pandas as pd

expenses = pd.DataFrame(
    {"category": ["Food", "Travel", "Food"], "amount": [12.50, 40.00, 18.25]}
)

food_expenses = expenses[expenses["category"] == "Food"]
by_category = expenses.groupby("category")["amount"].sum()

print(food_expenses)
print(by_category)
```

---

### 4. Reading a CSV File

```python
import pandas as pd

sales = pd.read_csv("sales.csv")
print(sales.head())
print(sales.info())
```

Check data types and missing values before drawing conclusions from a dataset.

### 📝 Notes

- Use `.head()` to inspect the first rows and `.describe()` to summarize numeric columns.
- Column names are case-sensitive.
- Keep the original data unchanged; store cleaned data in a new variable.
